# Experimental skills

Experimental skills that load with the plugin but are not yet stable.

## User-invoked

None yet.

## Model-invoked

- **[delivery-slice](./delivery-slice/SKILL.md)**: Turn an accepted Wayfinder branch outcome into a reviewable spec draft and dependency-linked vertical-slice ticket drafts using to-spec and to-tickets. Use after a bounded outcome is agreed; unresolved planning belongs with Wayfinder.
- **[test-runner](./test-runner/SKILL.md)**: Run Bun tests: pass/fail gates, coverage, repair of failures in files you are editing, and triage of broader suite failures. Also proves and benchmarks the runner itself.
