# Engineering skills

Daily code and repository hardening skills shipped in the plugin.

## User-invoked

- **[hello-world](./hello-world/SKILL.md)**: Portable reference skill backed by a bundled `agent-cli-kernel` CLI (`dist/cli.mjs`) with zero `node_modules`.
- **[weekly-hardening](./weekly-hardening/SKILL.md)**: Weekly 7-day determinism pass turning recent mistakes, CI flakes, suppressions, and loop friction into verified structural gates.

## Model-invoked

- **[ci-reproduce](./ci-reproduce/SKILL.md)**: Diagnose failing CI builds, tests or deployments when local checks pass, build inputs differ, or remote logs are unavailable. Reproduce the failing stage and verify the correction in CI.
- **[test-design](./test-design/SKILL.md)**: Design or change tests, fixtures, mocks, snapshots, helpers, or harnesses; audit test-writing anti-patterns; select a proportional brief or read-only verdict.
- **[xdg](./xdg/SKILL.md)**: XDG Base Directory v0.8 rules for CLI config, data, state, cache, and runtime directories.
